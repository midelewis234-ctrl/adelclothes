# 🚀 Quick Start Guide - Élégance Couture

Get your luxury tailor website up and running in minutes!

## 📦 Installation (1 minute)

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The website will open at `http://localhost:5173`

## 🔑 First Login (30 seconds)

1. Go to `http://localhost:5173/login`
2. Use these credentials:
   - **Email**: `admin@elegancecouture.com`
   - **Password**: `admin123`
3. Click "Sign In"

You're now in the admin dashboard! 🎉

## ⚡ Quick Setup (5 minutes)

### Step 1: Update Website Settings
1. Click "Website Settings" in the sidebar
2. Change:
   - Site Name (your business name)
   - Logo URL (your logo link)
   - Hero Title (your main headline)
   - Hero Subtitle (your tagline)
   - About Description (your story)
3. Click "Save Settings"

### Step 2: Update Contact Information
In the same settings page, scroll down and update:
- WhatsApp Number (format: +2348012345678)
- Email Address
- Phone Number
- Business Address
- Social Media URLs
- Click "Save Settings"

### Step 3: Change Hero Video (Optional)
1. Click "Hero Video" in the sidebar
2. Paste your video URL (must be .mp4 link)
3. Example: `https://example.com/yourvideo.mp4`
4. Click "Save Video"

**Free Video Sources:**
- Pexels.com (free videos)
- Pixabay.com (free videos)
- Mixkit.co (free videos)

### Step 4: Add Your Services
1. Click "Services" in the sidebar
2. Click "Add New"
3. Fill in:
   - Title (e.g., "Bespoke Suits")
   - Description
   - Image URL (from Unsplash or your hosting)
   - Price (e.g., "From ₦250,000")
   - Features (up to 4)
4. Click "Add Service"

Repeat for all your services!

### Step 5: Add Gallery Images
1. Click "Gallery" in the sidebar
2. Click "Add New"
3. Fill in:
   - Image URL
   - Title
   - Category (e.g., "Wedding", "Corporate")
4. Click "Add Item"

Add as many images as you want!

   - Right-click image → Copy Image Address

## 💬 WhatsApp Integration

Once you set your WhatsApp number in settings, customers can:
- Click the floating green button (bottom-right)
- Click WhatsApp in navbar
- Click WhatsApp in footer
- Click WhatsApp on contact page

All will open a direct chat with your business!

## 📧 Email Integration

Once you set your email in settings, customers can:
- Click email button in navbar
- Click email in footer
- Click email on contact page

All will open their email client to send you a message!

## 📅 Managing Bookings

When customers book appointments:
1. Go to "Bookings" in admin panel
2. You'll see all booking details:
   - Customer name, email, phone
   - Service requested
   - Date and time
   - Measurements
   - Messages
3. Click ✓ to approve
4. Click ✗ to cancel
5. Click trash icon to delete

## 🌟 Managing Testimonials

1. Click "Testimonials" in sidebar
2. Click "Add New"
3. Fill in:
   - Customer Name
   - Role/Title
   - Testimonial Text
   - Photo URL
   - Star Rating (3-5)
4. Click "Add Testimonial"

Testimonials appear on homepage instantly!

## 🎨 Changing Colors

1. Go to "Website Settings"
2. Find "Primary Color" (black by default)
3. Find "Secondary Color" (gold by default)
4. Click color picker
5. Choose your colors
6. Click "Save Settings"

Colors update instantly across the entire website!

## 🚀 Going Live (Production)

### Build the Website
```bash

```

This creates a `dist` folder with your website.

### Deploy (Choose One):

#### Netlify (Recommended - Free)

2. Drag and drop `dist` folder
3. Done! You get a free URL

#### Vercel (Free)
1. Go to vercel.com
2. Import your project
3. Deploy!

#### GitHub Pages (Free)
1. Push to GitHub
2. Enable Pages in repo settings
3. Select `dist` folder

#### Custom Domain
1. Deploy to any hosting
2. Point your domain
3. Done!

1. **Images**: Use 800px width for best performance
2. **Videos**: Keep under 10MB for fast loading
3. **WhatsApp**: Include country code (+234 for Nigeria)
4. **Testimonials**: Add 3-5 for best impact
5. **Services**: Keep descriptions concise (2-3 sentences)
6. **Gallery**: Add 12-24 images for variety
7. **Colors**: Test on mobile after changing

## 🐛 Troubleshooting

### Video not playing?
- Use direct .mp4 link
- Check URL is accessible
- File size under 50MB

### WhatsApp not working?
- Check number format: +2348012345678
- Remove spaces and dashes
- Include country code

### Images not loading?
- Use HTTPS URLs (not HTTP)
- Check URL in browser first
- Try different image host

### Changes not saving?
- Check browser console for errors
- Clear localStorage and try again
- Refresh the page
